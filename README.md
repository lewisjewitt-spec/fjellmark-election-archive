# Fjellmark Election Archive

A mobile-friendly, single-file web app for a private fictional election archive.

## Included
- Fjellmark flag branding (cyan, cream, navy, red star)
- Overview dashboard and sample fictional records
- Add, edit, delete election and referendum records
- Party vote share and election comparison
- JSON backup export and backup import
- Browser local storage

## Run it
Open `index.html` in a browser. For an iPhone Home Screen web app, host the file on a static web host, open the resulting URL in Safari, then choose Share -> Add to Home Screen.

## Important
The sample results are fictional. Browser storage is local to that browser/device and may be cleared. Export backups regularly. If hosted on a public static host, the website/code is public; do not put sensitive information in it.
